# Burning Kitchen

## Descripción

Burning Kitchen es un videojuego desarrollado en Java utilizando
Programación Orientada a Objetos (POO), arquitectura MVC y manejo de hilos.

El jugador controla una olla que debe atrapar alimentos positivos
para aumentar el puntaje y evitar objetos negativos o ataques enemigos
que pueden hacerle perder la partida.

Antes de iniciar el juego, el sistema solicita el nombre del jugador
para personalizar la experiencia.

El juego cuenta con animaciones, efectos visuales, sonidos,
contador de vidas, puntaje y temporizador durante la partida.

---

## Características principales

- Pantalla de bienvenida interactiva
- Solicitud del nombre del jugador antes de iniciar
- Movimiento del jugador con teclado
- Sistema de puntaje
- Sistema de vidas
- Temporizador de juego
- Enemigos animados
- Objetos enemigos con colisiones
- Animaciones con sprites
- Sonidos y efectos de audio
- Uso de hilos para animaciones y movimiento
- Interfaz gráfica desarrollada con Java Swing

## Cómo ejecutar el proyecto

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase principal del proyecto.
3. Ingresar el nombre del jugador.
4. Iniciar la partida y jugar.

## Objetivo del juego

Atrapar la mayor cantidad de alimentos positivos para conseguir puntos,
evitando objetos negativos y ataques enemigos antes de perder todas las vidas
o que el tiempo termine.
